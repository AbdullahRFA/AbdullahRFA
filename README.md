### 🎯 Core Engineering Domains & Specialized Skill Set

#### 1. 💻 Software Engineering & Full-Stack Web Development
- **Core CS & Problem Solving:** Strong foundation in Data Structures & Algorithms (DSA), Object-Oriented Programming (OOP), Algorithmic Thinking, Complexity Analysis, and Debugging (1000+ competitive programming problems solved across LeetCode, Codeforces, CodeChef, AtCoder, HackerRank, and GeeksforGeeks).
- **Frontend Engineering:** Building responsive, interactive, and accessible web interfaces using **Next.js (App Router, Server Actions)**, **React.js**, **Redux**, **TypeScript**, **JavaScript (ES6+)**, **HTML5**, **CSS3**, **Tailwind CSS**, and **Bootstrap**.
- **Backend Architecture & APIs:** Designing scalable server-side systems and RESTful APIs using **Python (Django, Django REST Framework, FastAPI, Flask)** and **Node.js (Express.js)**. Experienced in ORM data modeling, database migrations, Pydantic data validation, asynchronous request handling, and business logic implementation.
- **Authentication & Security:** Implementing Role-Based Access Control (RBAC), Token-Based Authentication (JWT), HTTP-only secure cookies, session management, and third-party SDK integrations (e.g., Resend Node SDK).
- **Database Design & Management:** Architecting relational and NoSQL schemas, writing complex queries, and managing transactions across **PostgreSQL**, **MySQL**, **SQLite**, **MongoDB**, **Supabase**, and **Firebase**.

#### 2. 🤖 Artificial Intelligence, Machine Learning & LLM Engineering
- **Data Science & Classical Machine Learning:**
  - **Exploratory Data Analysis (EDA) & Preprocessing:** Data wrangling, vectorization, and statistical analysis using **NumPy**, **Pandas**, **Jupyter Notebook**, and **Google Colab**; managing ML pipelines, feature scaling, and optimizing the Bias-Variance tradeoff (underfitting vs. overfitting).
  - **Supervised Learning (Regression & Classification):** Linear Regression (Least Squares), Regularization (**Ridge/L2, Lasso/L1**), Logistic Regression (Sigmoid), **K-Nearest Neighbors (KNN)**, and **Decision Trees** (Gini Impurity, Entropy, Pruning).
  - **Unsupervised Learning & Dimensionality Reduction:** **K-Means Clustering** (Elbow Method), **Hierarchical Clustering**, **DBSCAN**, and **Principal Component Analysis (PCA)**.
  - **Model Evaluation & Explainability:** Evaluating models via **MAE, RMSE, $R^2$**, **Confusion Matrix (TP, FP, TN, FN)**, **Precision, Recall, F1-Score**, **ROC-AUC**, and **SHAP** analysis.
- **Deep Learning & Computer Vision (CV):**
  - **Neural Networks & CNNs:** Designing Deep Neural Networks with **TensorFlow** and **Keras**; implementing forward/backpropagation, gradient descent optimization, batch normalization, and mitigating vanishing/exploding gradients.
  - **Image Classification & Transfer Learning:** Building Convolutional Neural Networks (convolution filters, kernels, stride, max/average pooling), image preprocessing, data augmentation, and deploying lightweight architectures like **MobileNet** for resource-constrained devices.
  - **Object Detection & Model Optimization:** Dataset collection and bounding-box annotation with **Roboflow**; fine-tuning **YOLO** models (IoU, Non-Maximum Suppression, mAP evaluation) for object tracking and heatmap generation; exporting models to **ONNX** and **TensorRT** for high-speed production inference.
- **Natural Language Processing (NLP), LLMs, RAG & Multi-Agent Systems:**
  - **NLP & Transformers:** Text preprocessing (Tokenization, Lemmatization, Stopword removal) using **NLTK** and **SpaCy**; word representations (**TF-IDF, Word2Vec CBOW/Skip-gram, GloVe**); Transformer architecture (Self-Attention, Scaled Dot-Product & Multi-Head Attention, Positional Encoding); fine-tuning **BERT, GPT, and T5** via **Hugging Face**.
  - **Prompt Engineering & LLM APIs:** Zero-shot, one-shot, and few-shot prompting; integrating **OpenAI GPT** and **Google Gemini AI** APIs; implementing **Function Calling** and structured JSON/table output parsing.
  - **LangChain & Autonomous AI Agents:** Building multi-step reasoning workflows with **LangChain** (Prompt Templates, Chains, Conversation Memory, **Agent Executor**), custom API/File tools, and OCR/PDF/CSV document Q&A pipelines; orchestrating collaborative **Multi-Agent Systems** with **CrewAI** and **AutoGen** for dynamic task delegation.
  - **Retrieval-Augmented Generation (RAG) & Vector Databases:** Designing end-to-end RAG pipelines including document ingestion, chunking, semantic embedding generation (**BERT / Sentence Transformers**), and high-dimensional vector similarity search using **FAISS** and **ChromaDB**.
- **MLOps & Production Model Deployment:**
  - Serving serialized ML/DL models (`joblib` / `pickle` / `ONNX`) via **FastAPI** (`/predict`, `/health`, `/info` endpoints with **Pydantic** validation and Swagger UI/ReDoc), containerizing services with **Docker**, tracking experiments with **MLflow**, and deploying to cloud platforms (**AWS, Google Cloud, Heroku**).

#### 3. 📱 Cross-Platform Mobile Application Development (Flutter)
- **UI/UX & Cross-Platform Engineering:** Developing responsive, high-performance mobile applications using **Flutter** and **Dart** with Material Design, custom widget-based architectures, adaptive layouts, and declarative routing with **go_router** and deep linking.
- **State Management & Scalable Architecture:** Structuring production codebases using **Riverpod**, **Hooks Riverpod**, `StreamBuilder`, **Feature-First Architecture**, and **MVCR (Model-View-Controller-Repository)** design patterns for clean separation of concerns.
- **Backend-as-a-Service (BaaS) & Real-Time Data:** Deep integration with **Firebase Authentication**, **Cloud Firestore** (atomic transactions, batched writes, real-time listeners), **Firebase Storage**, and **Supabase**.
- **Enterprise & Production Mobile Features:** Implementing **Offline-First** persistence (`shared_preferences`), **PDF Invoice & Report Generation** (`pdf`, `printing` with thermal & A4 printer support), interactive financial charts (**FL Chart**), REST API & `json_serializable` integration, media handling (`image_picker`, `url_launcher`), and on-device/cloud AI integration (**MobileNet** & **Google Gemini AI**).

#### 4. 🧪 Software Quality Assurance (SQA): Automation & Manual Testing
- **Manual Testing & QA Methodologies:** Comprehensive expertise in **SDLC**, **STLC**, and **Agile/Scrum** workflows; executing Functional, Non-Functional, Regression, Smoke, Sanity, Retesting, UAT, Exploratory, Black-Box, Positive/Negative, Boundary Value, and Edge-Case testing across UI, API, and Database layers.
- **Test Design, Management & Defect Tracking:** Authoring structured **Test Plans**, **Test Scenarios**, **Test Cases**, and **Test Checklists**; performing Expected vs. Actual verification and managing the complete **Defect Lifecycle** (reproducible bug reporting, severity vs. priority triage) using **Jira**, **TestRail**, Excel, and Markdown.
- **UI Test Automation:** Engineering maintainable End-to-End (E2E) automated test suites using **Playwright (TypeScript/JavaScript)** and **Selenium WebDriver (JavaScript)**. Implementing the **Page Object Model (POM)** design pattern, Data-Driven Testing, resilient custom locators, explicit/implicit waits, and complex workflow assertions.
- **API Testing & CI/CD Reporting:** Validating RESTful APIs using **Postman** and **Newman CLI** — covering HTTP methods, status codes, JSON schema & payload validation, pre-request scripts, automated test assertions, and dynamic environment variables. Generating rich execution reports via **Allure Reporting** and HTML/CLI runners, alongside AI-assisted QA workflows for requirement analysis and test generation.
